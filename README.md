# dinooo13/homebrew-tap

```sh
brew install --cask dinooo13/tap/pladder
```

[Pladder](https://github.com/dinooo13/pladder): push-to-talk dictation for macOS 26 on Apple Silicon. Update it with `brew upgrade`.

`Casks/pladder.rb` is written by Pladder's Release workflow from [`scripts/pladder.rb`](https://github.com/dinooo13/pladder/blob/main/scripts/pladder.rb) with every release. Change the cask there; the next release overwrites this copy.
